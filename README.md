# Telecomando TV

Telecomando Android per TV Samsung Tizen (testato per UE55MU6470, serie MU 2017).

- Tasti completi, croce direzionale, volume/canali con ripetizione tenendo premuto
- Touchpad: modalità gesti (frecce + OK) e puntatore (browser del TV)
- Avvio app (elenco letto dal TV), tastierino numerico, tastiera per scrivere testo
- Accensione con Wake-on-LAN, ricerca automatica del TV sulla rete
- Tasti volume del telefono collegati al TV

L'APK viene compilato da GitHub Actions a ogni push ed è scaricabile dalla pagina **Releases**.
